# PR-01: Payment domain rules: balance, quote, confirm, lifecycle, wording v1

## Goal
Implement the pure money rules of the payment slice in `src/CardLab.Domain` (tier-3 high-risk path, NFR-1): balance
arithmetic and pay availability, the reference format, the full-balance quote, the exactly-once / one-in-flight confirm
decision, the payment state machine, wording v1 (W-1..W-10, verbatim) and the payment wire names, plus `Money.ToDisplay`.
No I/O. Proven by unit tests and four FsCheck properties (AC-25). Everything later (services, API, UI) calls these.

**Rules (design §5).**
- `BalanceRules.Owed(approved, completed)` = approved − completed floored at £0.00 (`Money -` already floors).
  `Availability(owed, hasPending)`: £0.00 → NothingToPay; > £1,000,000.00 → AboveLimit; pending → PaymentPending; else
  Available (checked in that order; £1,000,000.00 exactly is Available, `MoneyBounds` is inclusive).
- `QuoteRules.Create`: Kind Full, Fee £0.00, Total = Amount, FromLabel = `Label(account.DisplayName, account.LastFour)`,
  ToLabel = `Label(cardName + " card", card.LastFour)`, authority from the account, Shown = `ReviewScreen(...)`.
- `ConfirmRules.Decide` precedence (PLANNER-DECISION, documented in the skeleton): own payment exists → Repeat; status
  Refused → RefuseAlreadyRefused(currentOwed); other pending → RefusePendingExists(ref, amount); currentOwed ≠ quote
  amount → RefuseBalanceChanged(currentOwed); else Create.
- `PaymentStateMachine.Apply`: Pending + Completed(at) → Completed with `BankDebitedAtUtc = at`; Pending + Refused(r) →
  Failed(r); Pending + NotReceived → Failed(NotReceived); Pending + Unknown → Ok(Pending → Pending); Completed/Failed +
  anything → Fail(message).
- `PaymentReference.TryParse`: regex `^PAY-[0-9A-HJKMNP-TV-Z]{8}$`, no trimming or case folding (DEC-8).
- `WordingV1.Receipt(state, reason, amount, balance, ref)`: Completed → W-2; Failed InsufficientFunds → W-3; Failed
  AccountUnavailable or NotReceived → W-4 (design §9: not-received uses the W-4 text); Pending → W-5; Failed with null
  reason → `ArgumentException`.
- `PaymentWireNames`: wire names of design §7 (`pending|completed|failed`, `insufficient_funds|account_unavailable|not_received`,
  `available|nothing_to_pay|above_limit|payment_pending`, `purchase|payment`, `cardholder_view|deploy_smoke`,
  `open|confirmed|refused`, `admin|cardholder`, `full`, event kinds snake_case of the enum name). `OriginFromHeader`:
  DeploySmoke only for the exact string `deploy-smoke` (DEC-15).
- `Money.ToDisplay()`: `£` + invariant `#,##0.00` (culture-independent).
