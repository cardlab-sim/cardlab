## Verdict: **APPROVE WITH FIXES**

Counts: blocker 0 · major 0 · minor 8 · nits (one line at the end).

This is a solid test-only PR. Every brief test is real, the spec literals match §17 word for word (W-1..W-9), and the
page objects use the PR-03 accessible names. The integration cross-path checks assert hand-written literals
("24900.00", "0001", 6 events), not values recomputed by the code under test. Privacy is covered three ways:
- T-E-4 scans the text and HTML of six pages plus every `/api/` response;
- T-I-13 scans response bodies, every log record and attribute, and the full DB dump;
- failure messages print last fours only (`panScanner.ts:25`).

On the smoke spec:
- It marks itself at `smoke/pay.spec.ts:11`, and T-I-18 proves only the exact header value counts.
- It never resets.
- It reads the paid amount through a pattern, so a demo balance above £1.00 is fine.
- It ends at £0.00, which is a valid demo state.
- It is already wired: `.github/workflows/deploy.yml:111` runs `--project smoke`, which picks up `smoke/**`.

The gaps are small: a few AC clauses that are asserted weakly (F2–F4), one intermittent Firefox failure of T-E-3 that I
couldn't capture (F1), and a few rule or robustness points.
