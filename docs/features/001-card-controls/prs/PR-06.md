# PR-06: SQL store, schema, seed and integration harness

## Goal
Persist everything in SQL Server: the EF Core model and first migration, `SqlCardStore` with the per-card
`sp_getapplock` (passing the shared contract suite), the HMAC card lookup, startup migrate + idempotent seed, the real
clock and actor, and the integration harness (`SqlTestDatabase`, `ApiFactory`, `InMemoryLogExporter`) that PR-08,
PR-09 and PR-11 use. After this PR the host starts against a real database.

## Design context (excerpts)
**Tables (design §6)** — EF model in `Model/`, first migration `InitialCardControls`; amounts `decimal(12,2)`; enums as
their C# names in `varchar` columns (`HasConversion<string>()` is not needed: the row classes hold strings; map
domain ↔ row in the store):

| Table | Columns | Keys / indexes |
|---|---|---|
| `BusinessAccount` | `Id uniqueidentifier`, `Name nvarchar(200)`, `TimeZoneId varchar(64)` | PK Id; unique Name |
| `AdminUser` | `Id`, `AccountId`, `DisplayName nvarchar(200)` | PK; FK Account; unique (AccountId, DisplayName) |
| `Card` | `Id`, `AccountId`, `Name nvarchar(100)`, `CardholderName nvarchar(200)`, `LastFour char(4)`, `LookupHash binary(32)`, `Status varchar(20)` | PK; FK Account; unique LookupHash; unique (AccountId, Name) |
| `SpendLimit` | `Id`, `CardId`, `Category varchar(40)`, `Period varchar(10)`, `Amount decimal(12,2)` | PK; FK Card; unique (CardId, Category, Period) |
| `Transaction` | `Id`, `CardId`, `Amount decimal(12,2)`, `Category`, `Merchant nvarchar(200)`, `OccurredAt datetimeoffset(0)`, `DecidedAtUtc datetime2(3)`, `Outcome varchar(10)`, `Reason varchar(20)` | PK; FK Card; `IX_Transaction_Spend (CardId, Category, Outcome, OccurredAt) INCLUDE (Amount)`; index `(CardId, DecidedAtUtc DESC)` |
| `AuditEvent` | `Id`, `CardId`, `ActorId`, `ActorName nvarchar(200)`, `AtUtc datetime2(3)`, `Action varchar(20)`, `OldValue nvarchar(400) null`, `NewValue nvarchar(400) null` | PK; FK Card; index `(CardId, AtUtc DESC)` |

`Transaction` and `AuditEvent` are append-only (no update/delete code paths). No card number column anywhere (NFR-1).
EF specifics: `IsFixedLength()` for `char(4)`/`binary(32)`, `HasPrecision(12, 2)`, `HasColumnType("datetimeoffset(0)")`,
`HasColumnType("datetime2(3)")`, `.IncludeProperties(t => t.Amount)` and `.IsDescending(false, true)` on the indexes.

**Migration files (exact names, for the scope check):** generate with `dotnet tool restore` then `dotnet ef migrations
add InitialCardControls --project src/CardLab.Infrastructure --startup-project src/CardLab.Api --output-dir Migrations`,
then rename the two migration files to `20261105000000_InitialCardControls.cs` / `.Designer.cs` and set
`[Migration("20261105000000_InitialCardControls")]` in the Designer file. Forward-only; never edit after merge.

**Per-card lock (DEC-4, ADR-002).** `WithCardLockAsync`: `await using var tx = await db.Database.BeginTransactionAsync(ct)`;
`EXEC @r = sp_getapplock @Resource = @resource, @LockMode = 'Exclusive', @LockOwner = 'Transaction', @LockTimeout = 5000`
via `ExecuteSqlRawAsync` with `SqlParameter`s (`@resource` = `card:{id}`, `@r` output int); `@r < 0` → roll back, throw
`CardLockTimeoutException` (message with the card id only); run work with a `SqlCardWriter`; `SaveChangesAsync`;
`CommitAsync` (releases the lock); on exception roll back and rethrow. Do not enable `EnableRetryOnFailure` (it forbids
user transactions). Spend: `SUM(Amount)` over approved rows with `OccurredAt >= StartUtc AND OccurredAt < EndUtcExclusive`
(`datetimeoffset` compares instants) — e.g. `SumAsync(t => (decimal?)t.Amount) ?? 0m`.

**Lookup (DEC-8):** `HMACSHA256.HashData(key, Encoding.ASCII.GetBytes(digits))`, key = `Convert.FromBase64String(
CardLab:LookupKey)` which must be exactly 32 bytes, else `InvalidOperationException` without the key in the message.

**Startup + seed (DEC-9):** `InitialiseDatabaseAsync`: create a scope, `db.Database.MigrateAsync()`, then
`Seeder.EnsureSeedAsync(scope.ServiceProvider, seedOptions)`. Seed (idempotent by name; admin by `AdminId`): account
"Brightline Supplies Ltd" (Europe/London), admin "Sam Ellis" (`AdminId` from options), cards from `SeedOptions.Cards`
(Active, no limits on creation); every run recomputes `LookupHash` and `LastFour` of each seeded card from its number.
**SystemClock** = `DateTimeOffset.UtcNow`; **SeededAdminActor** = `new Actor(options.AdminId, options.AdminName)`.

**Integration harness (§15.2):** `SqlTestDatabase` — database `CardLab_Test_<guid N>` on the server of
`CARDLAB_TEST_CONNECTION` (default `Server=(localdb)\MSSQLLocalDB;Trusted_Connection=True;TrustServerCertificate=True`;
set `Initial Catalog` with `SqlConnectionStringBuilder`); `InitializeAsync` migrates and seeds with a small
`ServiceCollection` (DbContext, `HmacCardNumberLookup` with `Seed.DevLookupKey`, `SeedOptions` matching `Seed`);
`DisposeAsync` clears pools and drops the database (`ALTER DATABASE ... SET SINGLE_USER WITH ROLLBACK IMMEDIATE; DROP
DATABASE ...` from `master`). `ApiFactory` — `UseEnvironment("Development")`, `UseSetting("ConnectionStrings:CardLab",
Database.ConnectionString)`, `UseSetting("CardLab:TestEndpoints", TestEndpointsEnabled ? "true" : "false")`,
`UseSetting("CardLab:Commit", "test-commit")`; `ConfigureServices(s => s.AddOpenTelemetry().WithLogging(l =>
l.AddProcessor(new SimpleLogRecordExportProcessor(Logs))))`; `InitializeAsync` initialises `Database` first; `DisposeAsync`
disposes the host then the database. `InMemoryLogExporter` copies `EventId.Name`, `Attributes` and `FormattedMessage` out of
each pooled `LogRecord` under a lock.

## Planner decisions (PLANNER-DECISION)
- `ApiFactory` owns its own `SqlTestDatabase` (exposed as `Database`) because xunit class fixtures cannot depend on each
  other; the design's "SqlTestDatabase and ApiFactory via IClassFixture" becomes one fixture for host tests.
- `SqlTestDatabase` arrange helpers (`SetStatusAsync`, `SeedLimitAsync`, `SeedTransactionsAsync`) let PR-08 set up state
  without the admin endpoints that PR-09 builds in parallel.
- Seeded admin id is fixed in configuration (`CardLab:Seed:AdminId`) so `SeededAdminActor` needs no query.
- Fixed migration timestamp `20261105000000` so the brief can name exact files.
