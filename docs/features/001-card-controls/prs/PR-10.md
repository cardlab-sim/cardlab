## Design context (excerpts)
**DEC-18.** The full Playwright suite (journeys, axe, keyboard, formatting, privacy) and the ZAP baseline run CI-local on
every PR against the published host + mssql service; only the `smoke` project runs against `demo` after deploy (one J-1
journey on "Ops van", restoring the card to active, plus the AC-36 timing). ZAP: `zaproxy/action-baseline` (pin the
latest `v0.x` tag, design expects `v0.12.x`) with `fail_action: true`, `rules_file_name: .zap/rules.tsv`,
`allow_issue_writing: false`; WARN-level findings are fixed or listed in `.zap/rules.tsv` with a one-line reason.

**CI e2e job (§14, DEC-5):** `needs: [backend, web]`; mssql 2022 service exactly as in the `backend` job; setup-dotnet +
setup-node 22; `npm ci --prefix web && npm run build --prefix web`; `dotnet publish src/CardLab.Api -c Release -o
publish`; start the host in the background with `ASPNETCORE_URLS=http://localhost:5080`,
`ASPNETCORE_ENVIRONMENT=Production`, `ConnectionStrings__CardLab` = the service connection string plus `Database=CardLab`,
`CardLab__TestEndpoints=true`, `CardLab__LookupKey` = the committed dev key (`jq -r .CardLab.LookupKey
src/CardLab.Api/appsettings.Development.json`), `CardLab__Commit=$GITHUB_SHA`; wait for `/api/health` 200; `npm ci --prefix tests/e2e`, `npx --prefix tests/e2e
playwright install --with-deps chromium`, `npm run e2e --prefix tests/e2e` (project `local`, `BASE_URL`); upload the
Playwright report on failure; then ZAP against `http://localhost:5080`. Keep the `ticket-key`, `backend`, `web` jobs as
they are (you may only add the Bicep or caching tweaks they need). Job names must stay `ticket-key`, `backend`, `web`,
`e2e` (required checks, DEC-21).

**Playwright config:** projects `local` (all specs except `smoke/**`, `baseURL` = `BASE_URL` or `http://localhost:5080`,
a `webServer` block for local runs: `command` from `CARDLAB_HOST_COMMAND` defaulting to `dotnet run --project
../../src/CardLab.Api`, `url: <base>/api/health`, `reuseExistingServer: true`, timeout 120 s) and `smoke` (`DEMO_URL`,
no webServer, no reset). `retries: process.env.CI ? 1 : 0`; reporter `list` + `html` (never opened).

**Journeys:** every `local` spec calls `await new Api(request).reset()` in `beforeEach` and ends with
`expectNoSeriousViolations(page)`. Page objects use role/label locators only. Card numbers from `seed.ts` are used only in
`api.ts` processor calls, never typed into the UI. Wire facts: decision reason codes as in §7; the simulate notice shows
the reason code; amounts `£1,234.56`; times `25 Oct 2026 00:30` (Europe/London; run the browser with
`timezoneId: 'UTC'` in T-E-6 to prove independence).

## Harness to use
Local run: start LocalDB, then `npm run e2e --prefix tests/e2e` (the `webServer` block starts the host with
`dotnet run --project src/CardLab.Api` in Development: LocalDB database `CardLab`, test endpoints on). Use
`@axe-core/playwright` `AxeBuilder` in `a11y.ts`. Use `request` fixture for `Api`. Keep specs independent: reset in
`beforeEach` (not in smoke).
